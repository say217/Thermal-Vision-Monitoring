Platform Features

Every module is engineered for reliability in environments where conventional systems fail — from smoke-filled corridors to pitch-dark perimeters.

Thermal Person Detection

YOLOv9c-powered detection on thermal video streams with per-frame confidence scores, bounding boxes, and stable cross-frame identity tracking.

Live Incident Streams

Real-time overlays with detection labels, confidence ratings, and thermal colormap rendering — readable at a glance by any operator.

AI Summary Engine

Gemini AI translates structured detection logs into concise incident narratives. Automatic fallback to raw logs ensures zero downtime.

Motion State Awareness

Each detected person is classified as standing or moving across frames, enabling nuanced behavioral assessment and density tracking.

Structured Event Logging

All detections are persisted to JSONL with width, height, confidence, frame ID, anomaly flags, and rolling density averages.

Multi-Module Monitoring

Seven Flask blueprint modules — dashboards, auth flows, thermal analysis, user management — each independently deployable and extensible.

Wildfire Module

Advanced wildfire detection continuously analyzes heat signatures, smoke behavior, and high-risk thermal anomalies to trigger early alerts before visible flame expansion. This module is built to support faster response decisions across forests, remote zones, and critical infrastructure edges.

Human Activity Module

Human Activity Detection

The human activity detection system tracks people across monitored zones, classifies movement patterns, and highlights unusual behavior in real time. It is designed to improve situational awareness for perimeter security, industrial safety, and crowd monitoring operations.

Mission

Built for Environments Where Visibility Is a Luxury

Standard surveillance fails the moment conditions turn hostile — dense smoke, absolute darkness, fog, or remote terrain beyond cable reach. Thermal Vision was engineered specifically for these scenarios. By operating on heat signatures rather than visible light, the platform maintains detection accuracy when RGB systems go blind.

From early wildfire identification in remote forest perimeters to 24/7 monitoring of industrial plants with toxic fume risk, Thermal Vision provides a persistent, intelligent eye that never tires. The YOLOv8 day/RGB system and YOLOv9 thermal system operate in tandem, ensuring seamless coverage across all lighting conditions.

Every alert is not just a flag — it's a narrated incident, structured log entry, and optional voice briefing, delivered in seconds to whoever needs to act.

Integration

How the Stack Works Together

The Flask application serves as the backbone, routing requests across seven blueprint modules. SQLAlchemy abstracts the MySQL layer for user authentication and event persistence, while the Ultralytics stack handles real-time inference.

YOLOv9c processes thermal frames server-side, writing detection metadata to structured JSONL logs. These logs feed directly into the Gemini summarization pipeline, which produces incident narratives on demand or at scheduled intervals.

pyttsx3 bridges the digital and physical — delivering audio briefings to operators in the field without requiring visual attention. The entire system is designed for modularity: each app blueprint can be deployed, updated, or replaced independently.
